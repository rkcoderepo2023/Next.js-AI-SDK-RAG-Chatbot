# Holy Places Android App (MVP)

This directory contains a Jetpack Compose Android app scaffold that implements the mobile product plan:

- Discovery of nearby holy places
- Planner-focused MVP feature cards
- Festival/events guidance
- Community growth features
- Trust & safety alerts

## Run locally

1. Open `android-app` in Android Studio (Koala or newer).
2. Let Gradle sync.
3. Run the `app` configuration on an emulator/device (API 26+).

## Notes

- The current implementation uses static sample data and UI scaffolding.
- Next steps include API integration for real places, timings, geolocation, and crowd updates.
